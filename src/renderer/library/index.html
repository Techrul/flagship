Game defaults

Flagship plays games with TurboWarp, a faster Scratch player. These options control how it runs them, and they apply to every game. To change something for just one game, use ⋯ → Game settings on its card. If you're not sure, leave things as they are: the standard settings match how games behave on Scratch.

Game settings

Most changes apply right away, even if the game is open. Stage size, compiler, warp timer, controller, mouse lock, cloud saves and skip-click-to-play apply the next time you launch it.
