Custom themes

Themes are small CSS files in your themes folder. Open the folder, copy example.css, change the colors, then hit Reload. They show up in the list above.

Setting profiles

Flagship plays games with TurboWarp, a faster Scratch player. A profile is a saved set of TurboWarp settings. Every game uses one: pick it when you add the game, or later in ⋯ → Game settings. Enhanced is recommended; switch a game to Vanilla if it acts weird.
